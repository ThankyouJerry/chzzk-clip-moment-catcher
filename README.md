# 치지직 클립 모먼트 캐처

[![Latest release](https://img.shields.io/github/v/release/ThankyouJerry/chzzk-clip-moment-catcher?label=release)](https://github.com/ThankyouJerry/chzzk-clip-moment-catcher/releases/latest)
[![QA and Build](https://github.com/ThankyouJerry/chzzk-clip-moment-catcher/actions/workflows/build.yml/badge.svg)](https://github.com/ThankyouJerry/chzzk-clip-moment-catcher/actions/workflows/build.yml)

치지직 VOD에서 내보낸 **채팅 CSV만 분석해** 편집 후보 구간을 찾는 로컬 데스크톱 앱입니다. 채팅 급증, 특정 키워드 급증, 정서 방향과 반응 강도를 분석하고 실제 채팅 피크를 기준으로 편집용 프리롤·포스트롤 구간을 제안합니다.

영상·음성을 직접 분석하거나 VOD를 다운로드하지 않습니다. 앱 자체의 모든 분석은 사용자 컴퓨터에서 실행되며 CSV나 채팅 내용이 별도 서버로 전송되지 않습니다. NAVER 또는 CHZZK의 공식·제휴 제품이 아닌 개인 오픈소스 프로젝트입니다.

**[최신 버전 다운로드](https://github.com/ThankyouJerry/chzzk-clip-moment-catcher/releases/latest)**

## 주요 기능

- 채팅량이 주변 구간보다 급증한 사건을 탐색합니다.
- `ㅋㅋ`, `레전드` 같은 키워드의 메시지 수와 실제 출현 횟수를 따로 계산합니다.
- 가까운 급증 구간을 하나의 사건으로 합치고, 원본 채팅에서 실제 피크 시각을 다시 찾습니다.
- 긍정·부정의 `정서 방향`과 반응이 얼마나 격한지 나타내는 `반응 강도`를 분리합니다.
- 결과를 탭으로 보관하고 사건 시작, 실제 피크, 분석량, 기준 대비 배수, 신뢰도, 고유 채팅 참여자 수와 반응 범위를 함께 표시합니다.
- 편집 작업표 CSV, Premiere 교환 XML, Final Cut FCPXML을 내보냅니다.
- `p001` 또는 `part001` 형태로 나뉜 채팅 CSV를 자동으로 찾아 순서대로 합칩니다.
- 시스템 메시지와 내용이 없는 빈 메시지는 분석 근거에서 제외합니다.
- 반복 반응어를 정규화한 표현 분포 이미지를 만듭니다.
- 긴 작업은 언제든 취소할 수 있고, 저장 중 오류가 나도 기존 출력 파일을 보존합니다.

## 다운로드

[최신 릴리스](https://github.com/ThankyouJerry/chzzk-clip-moment-catcher/releases/latest)에서 운영체제에 맞는 파일을 받습니다.

- Windows: `ChzzkClipMomentCatcher-Windows-x86_64.zip`
- macOS Apple Silicon: `ChzzkClipMomentCatcher-macOS-arm64.zip`
- macOS Intel: `ChzzkClipMomentCatcher-macOS-x86_64.zip`

ZIP을 **전체 압축 해제**한 뒤 실행하세요. Windows에서는 EXE와 `_internal` 폴더를 같은 위치에 유지해야 합니다. PyQt6 6.8의 지원 범위에 맞춰 Windows 10 1809 이상 또는 macOS 12 이상을 사용하세요. 배포 대상은 Windows x86_64와 macOS Intel·Apple Silicon이며, Windows ARM 등 다른 환경은 패키지 테스트 대상이 아닙니다.

Mac 종류는 Apple 메뉴의 `이 Mac에 관하여`에서 확인할 수 있습니다. 칩 항목이 `Apple M...`이면 Apple Silicon, 프로세서 항목이 `Intel`이면 Intel 빌드를 사용합니다.

macOS 빌드는 ad-hoc 서명되며 Apple 공증은 적용되지 않습니다. 처음 실행이 차단되면 앱을 한 번 실행한 다음 `시스템 설정 > 개인정보 보호 및 보안`에서 해당 앱의 `확인 없이 열기`를 선택하고 다시 확인하세요. 출처를 확인할 수 없는 다른 앱에 이 절차를 적용하지 마세요.

Windows 빌드도 코드 서명되지 않았습니다. 공식 Releases에서 직접 받은 파일인데 Microsoft Defender SmartScreen이 차단하면 `추가 정보 > 실행`을 선택할 수 있습니다. 다운로드 출처가 다르거나 파일이 변조된 것으로 의심되면 실행하지 마세요.

소스 코드로 실행하거나 기여하려면 [CONTRIBUTING.md](CONTRIBUTING.md)를 참고하세요.

## CSV 준비

[chzzk-chat-exporter](https://github.com/ThankyouJerry/chzzk-chat-exporter)에서 VOD 채팅을 수집해 내보낸 CSV를 사용할 수 있습니다. 공개 exporter의 `Timestamp,User ID,Message` 형식과 새 `재생시간,닉네임,id,메시지` 형식을 모두 자동 인식합니다. 새 형식의 필수 열은 `재생시간`, `닉네임`, `메시지`이며 `id`는 선택 항목입니다.

```csv
재생시간,닉네임,id,메시지
00:00:18,사용자A,abc123,{:customEmote:}
00:00:19,사용자B,def456,ㅋㅋㅋㅋ
```

- `재생시간`: `HH:MM:SS` 또는 `HH:MM:SS.sss`
- `닉네임`: 채팅 작성자 이름
- `id`: 익명 참여자 식별값이며, 고유 채팅 참여자 집계에 우선 사용하는 선택 항목
- `메시지`: 원본 채팅 내용

영문 열 형식의 `1970-...Z` 재생시간도 VOD 경과시간으로 변환합니다. 추가 열은 원본 분석 데이터에 유지되지만 편집 작업표와 XML에는 포함되지 않습니다.

분할 파일 이름이 `방송_d_p001.csv` 또는 `방송_part001.csv` 형식이면 확장자의 대소문자와 관계없이 어느 파일을 선택해도 같은 형식의 전체 묶음을 확인합니다. 첫 파일이나 중간 파일이 빠졌거나 열 구성이 다르면 분석하지 않고 정확한 오류를 표시합니다.

CSV는 따옴표가 포함된 쉼표·여러 줄 메시지를 지원하지만, 행마다 열 개수가 정확히 같아야 합니다. 현재 형식과 이전 형식의 열 이름이 한 파일에 동시에 있거나 NUL 같은 제어 문자가 포함된 파일은 잘못된 열로 분석하지 않고 오류를 표시합니다.

마지막 분할 파일 자체가 누락됐는지는 파일 이름만으로 판단할 수 없으며, 중복 행은 자동 제거하지 않습니다. exporter가 완료됐는지 확인하세요. 중복 비율과 재생시간 역행이 발견되면 입력 품질 경고를 표시하고, 중복이 많은 사건은 신뢰도를 낮춥니다.

한 번에 불러올 수 있는 입력은 전체 512 MiB, 500만 행, 64열까지이며 셀 하나는 262,144자까지입니다. 분석 화면이 감당할 수 있는 시간 구간은 최대 20,000개입니다. 이 제한은 비정상 파일로 인한 메모리 고갈과 UI 정지를 막기 위한 안전장치입니다. 매우 긴 VOD를 초 단위처럼 짧은 간격으로 분석하면 앱이 필요한 최소 간격을 안내하므로 그 값 이상으로 분석 간격을 늘려 다시 실행하세요.

## 사용 방법

1. `파일 선택`에서 채팅 CSV를 불러옵니다.
2. 목적에 맞는 분석을 실행합니다.
3. 결과 탭에서 전체 타임라인과 사건별 근거를 확인합니다. 결과 탭은 최근 12개까지 유지됩니다.
4. 편집 후보가 적절한지 VOD 화면과 함께 검토합니다.
5. 내보낼 결과 탭을 선택한 뒤 `편집 연동`에서 핵심 시점 앞뒤에 포함할 프리롤·포스트롤, 편집 타임라인과 같은 FPS, 출력 형식을 선택하고 `내보내기`를 눌러 저장 위치를 지정합니다. 분위기 작업표와 표현 분포 이미지도 화면에 선택된 해당 결과 탭을 저장합니다.
6. 생성된 CSV를 작업표로 사용하거나 XML을 편집 프로그램에서 가져옵니다.

분석 중 다른 작업을 실행할 수는 없습니다. 중단해야 하면 상단의 `취소`를 누르세요. 앱은 현재 계산을 안전하게 끝내고 결과를 추가하지 않은 채 대기 상태로 돌아갑니다.

- 처음 살펴볼 때: `채팅 밀도 분석`으로 주변보다 반응이 몰린 구간을 찾습니다.
- 특정 밈이나 반응을 찾을 때: `키워드 분석`으로 검색어가 반복된 구간을 찾습니다.
- 분위기 변화를 볼 때: `정서·반응 강도 분석`으로 긍정·부정 방향과 반응 세기를 확인합니다.

민감도가 높을수록 작은 변화도 더 많이 포착합니다. 짧은 영상처럼 시간 구간이 3개 미만이면 통계 판정을 강행하지 않고 `근거 부족`으로 표시합니다.

분위기 변화는 인접한 두 구간에 각각 정서 방향 근거 메시지가 2개 이상이고, 전체 메시지 대비 근거 커버리지가 3% 이상일 때만 표시합니다. 한두 메시지의 표현만으로 전체 분위기가 바뀐 것처럼 판정하는 오류를 줄이기 위한 최소 조건입니다.

## 편집 연동

### 편집 작업표 CSV

추천 시작, 실제 피크, 추천 종료, 분석량과 신뢰도를 표로 저장합니다. 소수점 시점은 밀리초까지 표시하며 각 시점의 숫자형 초 값도 함께 저장합니다. 사람이 검토하거나 스프레드시트에서 작업을 배분하기 위한 형식이며 편집 프로그램의 네이티브 프로젝트 파일은 아닙니다.

### Premiere 교환 XML

Final Cut Pro 7 `xmeml` 형식의 **마커 전용 별도 시퀀스**를 만듭니다. Premiere에서 `파일 > 가져오기`로 XML을 불러온 뒤, 생성된 `Clip Moment Markers` 시퀀스의 마커를 편집 시퀀스에 활용하세요. 기존 타임라인에 자동으로 마커를 추가하지 않습니다.

`29.97`과 `59.94` FPS는 NDF 타임코드로 생성됩니다. DF 타임라인에서는 표시 타임코드가 다르게 보일 수 있습니다.

### Final Cut FCPXML

마커 전용 **별도 FCPXML 프로젝트**를 만듭니다. Final Cut Pro에서 `파일 > 가져오기 > XML`로 불러오세요. 지원 FPS는 `23.976`, `24`, `25`, `29.97`, `30`, `50`, `59.94`, `60`이며 `29.97`과 `59.94`는 NDF 타임코드로 생성됩니다.

- [Apple FCPXML Reference](https://developer.apple.com/documentation/professional-video-applications/fcpxml-reference)

자동 테스트는 XML 파싱, 필수 요소와 프레임 계산을 확인합니다. 공식 스키마 검증이나 Premiere·Final Cut 실제 가져오기 테스트는 아니므로 원본 프로젝트 복사본에서 먼저 확인하세요.

채팅 CSV만으로는 실제 VOD 길이를 알 수 없으므로 추천 종료 시각은 마지막 채팅 뒤라도 요청한 포스트롤만큼 유지합니다. 그 결과 VOD 끝부분의 후보는 실제 영상 길이를 넘어갈 수 있으니 편집 프로그램에서 원본 길이에 맞게 잘라 주세요. 향후 미디어 길이가 함께 제공되는 입력에서는 그 경계를 넘지 않게 제한합니다.

## 지표 해석

### 채팅 사건

현재 구간을 제외한 주변의 비교적 조용한 구간과 변동 폭을 기준선으로 사용합니다. 긴 급증이 자기 자신을 기준선에 섞어 사라지지 않도록 낮은 쪽 배경값을 우선 사용합니다. 인접한 후보는 하나의 사건으로 합치되, 사이가 평소 수준까지 내려간 두 피크는 별개 사건으로 유지합니다. 밀도 분석의 마커는 사건 안에서 가장 밀집된 15초 전체 채팅의 중앙 시각에 생성되고, 키워드 분석은 해당 키워드를 포함한 메시지 안에서 피크를 찾습니다. 키워드 사건의 분석량은 메시지 수가 아니라 검색어의 실제 출현 횟수입니다.

### 신뢰도

신뢰도는 통계적 확률이나 검증된 정확도가 아닙니다. 변화 점수 45%, 기준 대비 배수 35%, 참여자 분산도 20%를 합친 0~1 범위의 휴리스틱 검토 우선순위이며, 사건 안의 중복 채팅 비율이 높으면 추가로 낮아집니다. 참여자는 CSV의 `id`를 우선 사용하고 값이 없을 때 정규화한 닉네임으로 추정합니다. 따라서 닉네임 대체 행은 실제 사람 수와 다를 수 있습니다.

한 참여자만 채팅한 사건은 `개인 집중`으로 표시하고 신뢰도를 최대 35%로 제한합니다. 두 명 이상이어도 한 참여자가 식별 가능한 채팅의 70% 이상을 차지하면 `소수 독점`으로 표시하고 최대 55%로 제한합니다. 그 외는 `다수 반응`으로 표시합니다. 이 구분은 채팅하지 않은 시청자를 포함하지 않으며 전체 시청자 반응률을 뜻하지 않습니다. 서로 다른 VOD나 분석 설정의 신뢰도를 절대값으로 비교하지 마세요.

### 정서 방향과 반응 강도

- 정서 방향: `-1`에 가까울수록 부정, `+1`에 가까울수록 긍정입니다.
- 반응 강도: 웃음, 울음, 놀람, 반복 문장부호, 커스텀 이모트가 얼마나 강한지 나타냅니다.
- 근거 커버리지: 해당 구간 메시지 중 정서 방향을 판단할 표현이 있었던 비율입니다.

이 분석은 한국어 채팅 휴리스틱이며 영상·음성의 의미를 이해하는 AI 모델이 아닙니다. 풍자, 밈, 스트리머별 은어는 오판할 수 있습니다. 조용하지만 중요한 장면은 놓칠 수 있고 도배, 레이드, 기술 장애처럼 채팅만 급증한 상황을 하이라이트로 오인할 수 있으므로 편집 전 원본 VOD 확인이 필요합니다.

`재미있지 않다`, `좋아하지 않는다` 같은 뒤따르는 부정 표현도 반영합니다. 전체 정서 방향은 분석 간격과 무관하게 같은 메시지 근거로 계산하며, 정서 근거가 3개 미만이면 수치 대신 `근거 부족`을 표시합니다. 표현 분포는 형태소 분석이 아니라 공백과 반복 반응 규칙을 사용하므로 조사 결합어가 따로 집계될 수 있습니다.

## 문제 해결

- 필수 열 오류: 지원 열 이름과 CSV 인코딩을 확인합니다.
- 행 구조 또는 제어 문자 오류: 오류에 표시된 파일과 행을 원본 exporter에서 다시 내보내거나 텍스트 편집기로 열 개수와 NUL 문자를 확인합니다.
- 입력 제한 초과: VOD별로 CSV를 나누거나 불필요한 열을 제거한 뒤 다시 불러옵니다.
- 시간 구간이 너무 많음: 오류에 표시된 최소 분석 간격 이상으로 값을 늘립니다.
- 결과가 없음: 더 높은 민감도를 선택하거나 분석 간격을 조정합니다. `근거 부족`이면 간격을 줄여 최소 3개 시간 구간을 만들거나 키워드·정서 분석을 사용합니다.
- 후보가 너무 많음: 더 낮은 민감도를 선택하고 도배 여부를 확인합니다.
- 재현 가능한 오류: 개인정보를 제거한 예시 CSV와 실행 환경을 [GitHub Issues](https://github.com/ThankyouJerry/chzzk-clip-moment-catcher/issues)에 남겨 주세요.

최근 수정 내용은 [CHANGELOG.md](CHANGELOG.md), 프로젝트 기여 방법은 [CONTRIBUTING.md](CONTRIBUTING.md)를 참고하세요.

## 개인정보와 저작권

채팅 CSV에는 닉네임, 식별자와 사적인 메시지가 포함될 수 있습니다. 로컬 분석은 서버 전송을 하지 않는다는 의미이며 파일 암호화, 익명화, 자동 삭제를 제공한다는 의미는 아닙니다. 원본 CSV뿐 아니라 표현 분포 이미지, 작업표, XML과 스크린샷도 공유 전에 개인정보와 플랫폼 정책을 확인하세요.

이 소프트웨어의 사용이나 MIT 라이선스는 방송 영상, 음악, 게임, 이미지, 출연자 등 제3자 콘텐츠를 복제·배포·게시할 권한을 부여하지 않습니다. 분석 결과를 이용한 편집과 게시 책임은 사용자에게 있으며 각 콘텐츠의 권리는 해당 권리자에게 있습니다.
